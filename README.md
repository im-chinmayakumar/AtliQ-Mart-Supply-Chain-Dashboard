📊 AtliQ Mart Supply Chain Dashboard — Built with Power BI
📦 Project Summary
This project focuses on analyzing the Supply Chain Efficiency of AtliQ Mart, using real-world KPIs to evaluate logistics performance and improve decision-making.

🎯 Key Performance Metrics Tracked:
OTIF% – On-Time In-Full Delivery

OT% – On-Time Delivery

IF% – In-Full Delivery

VOFR% – Vendor Order Fill Rate

LIFR% – Line Item Fill Rate

🛠️ Tools & Technologies Used
✅ Power BI for visualization and dashboarding

✅ SQL (MySQL Workbench) for data extraction and cleaning

✅ DAX for calculated metrics and data modeling
